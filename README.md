# AI Resume Analyzer & Job Fit Scorer

## Overview
This project analyzes a resume against a job description and provides insights using LLMs.

## Features
- Resume parsing (PDF)
- Job description comparison
- Skill gap analysis
- Suggestions for improvement

## Tech Stack
- Python
- Streamlit
- Groq API
- PyMuPDF

## Status
🚧 Prototype in progress.

## Goal
To understand structured prompting and real-world AI use cases in hiring.
